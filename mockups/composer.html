Composer rework — mockups

Four live mockups of the send field. Each pane below is clickable: type and press Enter to "send", use the attach button, drag files onto a pane, or paste an image — staged files show as chips/thumbnails and send with the message.

⏎ send  ·  ⇧⏎ newline  ·  drop files anywhere on a pane  ·  ⌘V paste image  ·  × removes an attachment

A — Unified card chosen — shipped

Everything lives inside one bordered card: attachments on top, borderless textarea, then a toolbar row with attach, the device/model chips, and a round send button. The meta strip folds into the card, so the whole composer reads as a single control. Familiar from modern chat apps, still quiet enough for the paper theme.

B — Floating composer

The composer floats over the transcript on a soft shadow with a larger radius — the most "app-like" option. Same interior as A (attach, chips, round send) plus a mono hint line underneath. Trade-off: it overlaps the last message row and is the biggest visual departure from the current flat style.

C — Refined split

Smallest structural change: keeps today's input row and meta strip, adds a bordered attach button to the left, a staged-file tray above the input, and swaps the Send label for a square arrow button. Least modern, but also the least churn — every existing selector survives.
