Research pane — mockups

What the right pane could show while the agent is doing API-side research — web_search / fetch_url never touch the desktop, so today the stream is dead air. Every proposal keeps the same anatomy (live counters header · variant canvas · sources shelf + idle-desktop thumb) and replays the same scripted run: the main agent fires two parallel searches, then two helpers spin up and research alongside it. The last beat is a screen action — the board fades back to the desktop, which is how the auto-swap would feel live.

Today — dead air reference

The current pane during a research stretch: the stream is live, the status chip even knows a search is running — but the desktop itself has nothing to show. That's the gap.

agent working · desktop idle

A — Command deck proposal

One lane per worker: the main agent on top, helpers slide in with their own accent color and collapse to a summary line when collected. Query cards shimmer while in-flight (same physics as the status line) and resolve to a count + backend badge. Reads as parallel labor, not a log. Kept with the pill-shelf below for contrast — D–F move the sources elsewhere.

D — Harvest rows proposal

Same deck, but the bottom shelf is gone: when a query resolves, its sources land inside the card as an overlapping favicon stack — the avatar-row pattern. Each result is owned by the query that found it; the idle-desktop thumb floats over the board.

E — Rain rail proposal

The deck plus a narrow harvest rail on the right edge: every new source rains in as a bare favicon dot and stacks loosely — abstract, kinetic, zero text. The most ambient way to show yield.

F — Pipeline proposal

Motion-first: each lane has a segmented track under its header (one tick per call, filling as calls resolve), and done cards collapse to compact single lines after a beat — live work stays big and shimmering, finished work densifies behind it.

B — Constellation ambient alt

Ambient mode: workers are satellites, results fly from satellite to core, and the core grows with every source gathered. Least literal, most "something is alive in there." The query chips next to each satellite keep it honest.

C — Waterfall ambient alt

The ops-console take: a column per worker, cells stream top-down, each resolving to a compact count + backend. Densest of the three — scales to many parallel helpers without vertical sprawl, and the most professional in feel.

Data note: every variant consumes the same events — action{tool,args,agent}, search_result{query,backend,results[],agent}, fetch_result{url,title,agent}, plus the existing thought/subagent lifecycle. Helper accent hues are new tokens; everything else rides on existing CSS. All animation honors prefers-reduced-motion.
